Fatia Certa 🍰

Landing page para divulgação e pedidos de bolos, desenvolvida para a MR Sabores da Vida. Site estático, responsivo, com galeria de produtos, sistema de comentários e formulário de pedido integrado ao WhatsApp.

Funcionalidades:
Vitrine de produtos (seção com galeria dos bolos disponíveis.)
Avaliações de clientes (formulário de comentários com nota (1 a 5 estrelas), persistidos no localStorage do navegador.)
Pedido via WhatsApp (formulário estruturado (tipo, tamanho, sabor, data, detalhes) que gera uma mensagem formatada e abre o WhatsApp automaticamente.)
Layout responsivo (adaptado para desktop, tablet e mobile.)

Tecnologias:
HTML5
CSS3 (Flexbox e Grid)
JavaScript (Vanilla)

Estrutura do projeto
├── index.html      # Estrutura das seções (início, sobre, bolos, comentários, contato)
├── style.css        # Estilos e responsividade
├── script.js         # Lógica de comentários e envio de pedidos
└── fatiacerta.ico   # Favicon
